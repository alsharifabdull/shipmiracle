Agents

7
  • Ten named rolesScoper to reporter, installed once.
  • A model per roleOpus plans, Sonnet builds, Haiku summarises.
  • A separate verifierTests run by another agent.
  • Two review lensesCorrectness, or risk.
  • An agent capLimits how many agents run.
  • A team table per projectWho is on each project, in a table.
  • Skills you approvePinned to a commit.

Flow and approvals

6
  • Seven stagesBrief to Done.
  • Your OK is yoursOnly your own words in the chat approve a plan.
  • Change requestsEach change gets an id: shipm cr open, list, show, start.
  • Retry, then askTwo failed tries, then it waits for you.
  • A flow gateSays what was skipped.
  • Autopilot with a charterBounded runs that stop at hard stops.

Memory

5
  • Handoff in filesSTATUS.md, DECISIONS.md and memory/ in every project.
  • Project templatesA base plus web, iOS, Python, API, notes.
  • One engineering standardThe same rules in every project’s CLAUDE.md.
  • An ideas listdocs/FEATURE-IDEAS.md per project. Add with shipm idea add.
  • A nudge before chats driftA hint at 200k tokens, a strong one at 300k.

Automation

7
  • An awake guardKeeps the Mac awake for work. macOS.
  • Awake while Claude worksIdle sleep is held off for each call.
  • Continue at the usage limitThe Mac stays awake until the limit resets.
  • Keep goingClaude is sent back to finish.
  • A daily jobEvery day at 09:00.
  • A weekly tidy reportRead-only disk use per project.
  • Long jobs with a deadlineshipm bg 30 -- cmd ends the job when time is up.

Safety

6
  • A safety gate in hooksEach step is checked. Skips are said out loud.
  • Hard stopsA public push or deploy waits for you.
  • A push checkAn offline pre-push guard applies your registry rules.
  • Owner commands stay out of chatSetup and uninstall refuse to run in a chat.
  • Local, and maskedNo network calls of its own. Secrets are masked.
  • Hooks fail openA missing hook shows “gate OFF” instead of failing.

Setup

5
  • Guided setupshipm init is safe to re-run and can be resumed.
  • Check onlyshipm init --check and shipm doctor change nothing.
  • Quick setupFive choices in one card.
  • macOS, Linux, WSL 2macOS first. Linux and WSL 2 are experimental.
  • Reversibleshipm uninstall shows a dry run, then reverses writes.

Install in three commands

Run them in a normal terminal, not inside a Claude chat.

  1. Get the code
    $git clone https://github.com/alsharifabdull/shipmiracle ~/Developer/shipmiracle
  2. Move in
    $cd ~/Developer/shipmiracle
  3. Run the guided setup
    $./bin/shipm init

Only looking? shipm init --check changes nothing.

You need

  • macOS
  • Linux or WSL 2 (experimental)
  • Claude Code, Pro or Max login
  • VS Code
  • git, python3, node

Questions

Is it really free?

Yes. MIT licensed. You need your own Claude Pro or Max plan.

Do I need an API key?

No. It drives Claude Code with the login you already have.

Does it send my code anywhere?

No. It runs on your machine, with no network calls of its own.

Do I still use Claude Code?

Yes. Shipmiracle works with the Claude Code you already use. It keeps your AI projects organized, with plans, approvals, memory and status for each.

Where does it run?

Runs locally on macOS, Linux and Windows (through WSL 2); Linux and WSL 2 are experimental.

Is it affiliated with Anthropic?

No. It is independent. Claude and Claude Code are Anthropic’s products.
